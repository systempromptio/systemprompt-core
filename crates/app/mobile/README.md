The binding layer of systemprompt.io for phones: the surface the iOS and Android apps call.

The crate declares no items and has no dependencies.

**Layer**: App. The phone application crate: it composes the device and client slices a phone uses and depends on no server crate above the shared layer. Part of the [systemprompt-core](https://github.com/systempromptio/systemprompt-core) workspace.
