# Persisted vocabularies: one Rust enum per CHECK-constrained column.
#
#   table.column|schema.sql|enum.rs|EnumName[|open]
#
# lint-sql-vocab.sh verifies, per line, that the schema's CHECK (column IN (...))
# set equals the enum's as_str()/Display string set and that the SQL DEFAULT is
# the enum's #[default] variant. An `open` vocabulary (closed principals plus
# installation-defined names) only has to carry a CHECK and a DEFAULT that the
# enum spells. For every registered column, a `column = '<lit>'`,
# `column <> '<lit>'` or `column IN ('…')` literal inside a sqlx::query*! string
# in crates/**/src fails: bind the enum's as_str() instead.
#
# Rule for the same script: the literals `is_bot = false` and
# `is_behavioral_bot = false` inside a sqlx::query*! string in crates/**/src
# fail everywhere; the human-traffic predicate is the SQL function
# is_human_traffic(is_bot, is_ai_crawler, is_scanner, is_behavioral_bot)
# (crates/domain/users/schema/user_sessions.sql), called directly or through
# v_clean_traffic / v_engaged_traffic. The allowlist is empty.
