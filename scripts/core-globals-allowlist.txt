# Process statics the core-globals gate accepts, one per line:
#   path:NAME — reason
# Entries marked "debt" are service state that a later package moves into an
# owner; they are listed so the gate ratchets (no new statics) rather than
# accepted as a pattern. "immutable data" marks compiled regexes, const tables
# and link-time inventories that are set once and never mutated.

# Bootstrap chain (profile → secrets → config → services root): read by every
