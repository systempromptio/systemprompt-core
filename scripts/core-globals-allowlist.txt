# Process statics the core-globals gate accepts, one per line:
#   path:NAME — reason
# Entries marked "debt" are service state that a later package moves into an
# owner; they are listed so the gate ratchets (no new statics) rather than
# accepted as a pattern. "immutable data" marks compiled regexes, const tables
# and link-time inventories that are set once and never mutated.

# Bootstrap chain (profile → secrets → config → services root): read by every
# layer before an AppContext exists; replacing it is its own release.
crates/infra/config/src/bootstrap/profile.rs:PROFILE — bootstrap chain: the profile every layer reads before AppContext exists
crates/infra/config/src/bootstrap/profile.rs:PROFILE_PATH — bootstrap chain: where the active profile was loaded from
crates/infra/config/src/bootstrap/secrets/reload.rs:SECRETS — bootstrap chain: the secrets snapshot the reload swaps
crates/infra/config/src/bootstrap/secrets/reload.rs:GENERATION — bootstrap chain: secrets reload generation counter
crates/infra/config/src/bootstrap/secrets/reload.rs:STATUS — bootstrap chain: last secrets reload status
crates/infra/config/src/bootstrap/secrets/reload.rs:RELOAD_LOCK — bootstrap chain: serialises secrets reloads
crates/shared/manifest/src/config/mod.rs:CONFIG — bootstrap chain: the resolved Config read before AppContext exists
crates/infra/loader/src/services_root.rs:ACTIVE_ROOT — bootstrap chain: the resolved services root
crates/infra/loader/src/services_bootstrap.rs:SERVICES — owned by config-arch Phase 3
crates/infra/loader/src/services_bootstrap.rs:DISCOVERY — owned by config-arch Phase 3
crates/infra/loader/src/config_loader/mod.rs:CONFIG_CACHE — owned by config-arch Phase 3
crates/entry/api/src/routes/gateway/bridge_services_cache.rs:CACHED — owned by config-arch Phase 3

# Gateway failover statics (config-arch session hand-off).
crates/infra/security/src/credential/mod.rs:PROVIDER_TOKENS — debt: ProviderCredential::bearer is called from domain/ai upstream/target.rs and loader vertex_discovery (config-arch session); the owned form is TokenCache

# Immutable data: compiled once, never mutated.
crates/shared/models/src/ai/execution_plan.rs:TEMPLATE_REF_REGEX — immutable data

crates/shared/extension/src/gateway_guard.rs:GATEWAY_GUARDS — immutable data: link-time inventory of gateway guards, collected once
crates/domain/mcp/src/lib.rs:VERSION — immutable data: the MCP protocol version string rendered once
crates/domain/mcp/src/services/ui_renderer/artifact_ui.rs:REGISTRY — immutable data: the built-in UI renderer set, built once
crates/entry/api/src/routes/gateway/otel/mod.rs:NO_SUBJECT_DIMENSIONS — immutable data: the empty subject-provider set for unauthenticated OTLP ingest

# Third-party set-once globals mirrored by a static.
