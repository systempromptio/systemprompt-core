# The supported compositions of the `systemprompt` facade. A feature set not
# listed here is unsupported. CI builds every line (the Compositions job of
# .github/workflows/ci.yml) and boots each line flagged `boot`;
# scripts/build-report.sh measures every line.
#
# One composition per line: <name> <comma-separated facade features> [flags]
# Features are those of the `systemprompt` facade (systemprompt/Cargo.toml);
# `default-features = false` is always set, so list `core` explicitly.
# Flags (comma-separated):
#   boot     the composition links the `systemprompt` binary; CI runs
#            `systemprompt --help`, which declares every member and builds the
#            command tree from the admitted commands.
#   largest  the composition that also gets `cargo bloat --crates` and
#            `cargo build --timings`. Exactly one line carries it.
# A composition without `boot` is a library composition: it is compiled, and
# its build-report binary is a trivial `main` whose size measures only what
# survives dead-code elimination, while its closure counts are exact.
reference              reference              boot
reference-slack-teams  reference,slack,teams  largest,boot
api                    api
cli                    core,cli
gateway                api,ai
kernel                 core,database
extension              core
